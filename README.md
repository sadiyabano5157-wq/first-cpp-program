# Hello World in C++

## 📌 Description
This is a simple C++ program that prints "Hello" on the screen.

## 🚀 How It Works
- Include the iostream header file.
- Use the standard namespace.
- Print the message using `cout`.
- End the program with `return 0`.



## 📤 Output

```text
Hello
```

## 🛠️ Concepts Used
- C++
- iostream
- cout
- main() function

## 🎯 Learning Outcome
- Understanding the basic structure of a C++ program
- Using `cout` for output
- Writing and compiling a simple C++ application
